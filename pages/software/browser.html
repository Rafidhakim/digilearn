Browser Web (Peramban Internet)

Modul Micro-Learning 15 dari 25

1. Pengertian Browser Web (Peramban Internet)

Browser Web adalah aplikasi perangkat lunak yang digunakan untuk mengakses, mengambil, menerjemahkan, dan menampilkan halaman informasi di dalam jaringan World Wide Web (WWW).

2. Fungsi Utama

  • Menerjemahkan bahasa pemrograman web (HTML, CSS, JS) menjadi tampilan visual.
  • Memungkinkan pengguna menjelajahi situs web, menonton video, dan belanja online.
  • Menyimpan riwayat jelajah, markah (bookmark), dan password akun secara aman.

3. Cara Kerja Sederhana

Saat Anda mengetik alamat URL (misal: google.com), Browser mengirimkan permintaan HTTP ke server web tujuan, lalu mengunduh kode web dan merendernya menjadi visual halaman web.

4. Contoh Penggunaan Sehari-hari

Google Chrome, Mozilla Firefox, Microsoft Edge, dan Apple Safari.

Tips Pemula

Gunakan ekstensi pemblokir iklan (ad-blocker) dan jangan menyimpan password perbankan secara sembarangan di browser umum.

Fakta Menarik

Browser web pertama di dunia bernama WorldWideWeb diciptakan oleh Tim Berners-Lee pada tahun 1990.

Istilah Penting

URL: Alamat unik halaman web di internet.
Cache: Penyimpanan sementara data web agar pemuatan berikutnya lebih cepat.
Cookie: Berkas kecil penanda identitas sesi sesi login Anda di web.

Ringkasan Materi

  • Browser Web adalah jendela aplikasi untuk mengakses informasi di internet.
  • Menerjemahkan kode HTML/CSS menjadi tampilan visual web yang menarik.
  • Google Chrome, Firefox, dan Edge adalah browser yang populer digunakan.
