Antivirus & Keamanan Sistem

Modul Micro-Learning 19 dari 25

1. Pengertian Antivirus & Keamanan Sistem

Antivirus adalah program utilitas keamanan yang dirancang untuk mendeteksi, mencegah, mengkarantina, dan menghapus perangkat lunak berbahaya (malware, virus, ransomware, trojan) dari sistem komputer.

2. Fungsi Utama

  • Memindai (scan) berkas komputer dari bahaya kode jahat yang tersembunyi.
  • Melindungi sistem secara real-time saat mengunduh file atau mencolokkan flashdisk.
  • Membersihkan atau mengkarantina berkas terinfeksi agar tidak merusak Windows.

3. Cara Kerja Sederhana

Antivirus mencocokkan kode program di komputer dengan basis data tanda tangan virus (virus signature) terpercaya, serta memantau perilaku mencurigakan yang mencoba mengubah sistem.

4. Contoh Penggunaan Sehari-hari

Windows Defender (keamanan bawaan Windows) yang langsung memperingatkan Anda saat file yang baru diunduh ternyata berbahaya.

Tips Pemula

Cukup gunakan satu program antivirus aktif (seperti Windows Defender bawaan) agar kinerja komputer tidak menjadi lambat akibat bentrok.

Fakta Menarik

Virus komputer pertama yang diciptakan untuk merusak PC bernama 'Brain' dirilis pada tahun 1986 oleh dua bersaudara dari Pakistan.

Istilah Penting

Malware: Perangkat lunak jahat perusak sistem komputer.
Real-time Protection: Perlindungan aktif tanpa henti saat komputer menyala.
Quarantine: Pengisolasian berkas terinfeksi ke area aman.

Ringkasan Materi

  • Antivirus berfungsi mengamankan komputer dari serangan kode jahat/virus.
  • Melakukan pemindaian file saat mengunduh dari internet atau flasdisk.
  • Windows Defender bawaan Windows 11 sudah sangat memadai bagi pemula.
