DNS (Domain Name System)

Modul Micro-Learning 20 dari 20

1. Pengertian DNS

DNS (Domain Name System) adalah sistem pangkalan data terdistribusi yang menerjemahkan nama domain situs yang mudah diingat manusia menjadi kode alamat IP angka komputer.

2. Fungsi Utama

  • Menerjemahkan nama domain (contoh: google.com) menjadi IP Address (contoh: 142.250.190.46).

3. Cara Kerja DNS

Saat Anda mengetik nama domain, komputer mengirimkan query ke DNS Server. DNS Server mencari nomor IP pencocokan dalam buku alamat global lalu mengembalikan datanya ke komputer Anda.

4. Contoh Penggunaan

Mengetik youtube.com tanpa perlu menghafal deretan nomor IP angka server YouTube.

5. Tips Pemula

Tips: Menggunakan DNS publik cepat seperti Cloudflare (1.1.1.1) atau Google (8.8.8.8) dapat mempercepat respon browsing.

6. Fakta Menarik

Fakta: Tanpa DNS, kita harus menghafal kombinasi kode angka IP rumit untuk setiap website di dunia!
