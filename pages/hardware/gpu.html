GPU (Graphics Processing Unit)

Modul Micro-Learning 04 dari 25

1. Pengertian GPU (Graphics Processing Unit)

GPU (Graphics Processing Unit) atau kartu grafis adalah prosesor khusus yang dirancang untuk mengolah data visual, gambar, animasi, video, dan grafik 3D sebelum ditampilkan ke layar monitor.

2. Fungsi Utama

  • Merender piksel gambar dan video agar muncul di layar monitor.
  • Memproses objek 3D dan efek pencahayaan pada game atau software desain.
  • Meringankan beban CPU dalam mengolah grafis dan visual berat.

3. Cara Kerja Sederhana

GPU menerima perintah visual dari CPU, lalu menggunakan ribuan inti pemroses kecilnya secara paralel untuk mengkalkulasi koordinat piksel, warna, dan pencahayaan dengan cepat.

4. Contoh Penggunaan Sehari-hari

Saat Anda memutar video resolusi tinggi 4K atau bermain game 3D, GPU bekerja keras membentuk setiap bingkai gambar (frame) per detik.

Tips Pemula

Untuk kebutuhan mengetik dokumen dan browsing internet, GPU terintegrasi pada CPU sudah cukup tanpa perlu membeli VGA discrete mahal.

Fakta Menarik

GPU modern tidak hanya dipakai untuk visual game, tetapi juga digunakan untuk komputasi AI (Kecerdasan Buatan) dan pemrosesan data sains skala besar.

Istilah Penting

VRAM: Memori khusus pada kartu grafis untuk menyimpan data tekstur.
Integrated Graphics: GPU yang menyatu di dalam chip CPU.
Dedicated GPU: Kartu grafis terpisah dengan performa lebih tinggi.

Ringkasan Materi

  • GPU bertanggung jawab mengolah data visual dan grafis ke monitor.
  • Sangat penting untuk bermain game 3D, video editing, dan desain grafis.
  • Memiliki VRAM khusus untuk menyimpan tekstur gambar.
