Heatsink / CPU Cooler

Modul Micro-Learning 08 dari 25

1. Pengertian Heatsink / CPU Cooler

Heatsink / CPU Cooler adalah alat pendingin khusus yang dipasang di atas permukaan CPU untuk menyerap, mengalirkan, dan membuang panas ekstrem yang dihasilkan saat CPU bekerja.

2. Fungsi Utama

  • Menjaga suhu operasional CPU tetap aman di bawah batas maksimal.
  • Mencegah terjadinya thermal throttling (penurunan performa akibat panas).
  • Memperpanjang umur pakai chip prosesor agar tahan lama.

3. Cara Kerja Sederhana

Panas dari CPU diserap oleh permukaan tembaga/alokasi pendingin, dialirkan melalui pipa panas (heatpipe) menuju sirip-sirip logam, lalu ditiup oleh kipas angin keluar dari heatsink.

4. Contoh Penggunaan Sehari-hari

Saat CPU bekerja 100% merender video, Heatsink mencegah CPU mengalami overheat mati mendadak.

Tips Pemula

Jangan lupa untuk mengoleskan pasta thermal (thermal paste) di antara CPU dan Heatsink agar transfer panas berjalan sempurna.

Fakta Menarik

Selain pendingin udara (Air Cooler), ada juga pendingin cairan (Liquid/AIO Cooler) yang menggunakan selang berisi cairan khusus pendingin.

Istilah Penting

Thermal Paste: Gel konduktor penyalur panas antara CPU dan Heatsink.
Thermal Throttling: Pengurangan kecepatan otomatis CPU untuk menurunkan suhu.
AIO Cooler: Sistem pendingin cairan tertutup.

Ringkasan Materi

  • Heatsink menyerap dan membuang panas ekstrem dari chip CPU.
  • Pasta thermal wajib dioleskan di antara CPU dan permukaan Heatsink.
  • Mencegah CPU mengalami overheat dan penurunan kinerja.
