CPU (Central Processing Unit)

Modul Micro-Learning 01 dari 20

1. Pengertian CPU

CPU (Central Processing Unit) atau prosesor adalah komponen mikrochip utama yang bertindak sebagai "Otak Komputer". CPU mengeksekusi semua instruksi dari program perangkat lunak dan mengendalikan jalannya data di dalam komputer.

2. Fungsi Utama

  • Menerjemahkan instruksi dari program aplikasi komputer.
  • Melakukan perhitungan aritmatika (matematika) dan operasi logika.
  • Mengatur lalu lintas komunikasi data antarkomponen di Motherboard.

3. Cara Kerja CPU

Cara kerja CPU terbagi dalam siklus dasar Fetch - Decode - Execute:

  1. Fetch: Mengambil instruksi program dari memori RAM.
  2. Decode: Menerjemahkan instruksi tersebut menjadi sinyal biner (0 dan 1).
  3. Execute: Menjalankan kalkulasi perintah pada ALU (Arithmetic Logic Unit).

4. Contoh Penggunaan Sehari-hari

Saat Anda mengklik tombol "Hitung" pada rumus spreadsheet Excel, CPU memproses rumus matematika tersebut dalam jutaan kalkulasi per detik.

5. Tips Pemula

Tips: Pilih CPU dengan jumlah Core minimal 4 core untuk kebutuhan multitasking harian di Windows 11.

6. Fakta Menarik

Fakta: CPU modern memiliki miliaran transistor mikroskopis berukuran nanometer di dalam keping silicon seluas ibu jari.
